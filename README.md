# 2학년 프로그래밍 심화 탐구
추가 탐구-데이터베이스 구현 방법
1. 프로젝트 개요
기존 PROJECT : LOGIC에서 사용한 브라우저 기반 저장 방식과 SQLite의 데이터 저장 구조를 비교하기 위한 실험용 웹 애플리케이션이다.

기존 프로젝트에서는 JavaScript의 localStorage에 게임 진행 정보를 JSON 문자열로 저장하고, Streamlit의 st.session_state로 페이지 및 세션 상태를 관리하였다. 이번 프로젝트에서는 SQLite를 연동해 데이터를 테이블 형태로 저장하고, 두 방식의 구조와 차이를 직접 확인하고자 한다.
2. 핵심 구현 내용
- 저장 방식 시각화: 기존 localStorage의 데이터 저장 흐름과 SQLite의 저장 흐름을 단계별로 표현하고, st.session_state의 역할을 별도로 구분
- SQLite 데이터 관리: records.db 파일과 records 테이블을 생성하고 데이터의 저장·조회·수정·삭제 기능 구현
- 데이터베이스 구조 확인: 테이블의 열(Column), 행(Row), 자료형, 기본 키 및 제약 조건과 실제 저장된 데이터 확인
3. 탐구 목적
브라우저 기반 저장 방식과 관계형 데이터베이스의 저장 위치, 데이터 구성 및 관리 방식의 차이를 비교하고, SQLite가 웹 애플리케이션에서 데이터를 구조적으로 관리하는 과정을 직접 확인하는 데 목적이 있다.
